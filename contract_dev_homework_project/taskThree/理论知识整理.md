## Foundry 框架三大核心组件
Foundry 是一个高度集成的 Rust 编写的以太坊智能合约开发工具链，主要由以下三个工具组成：

+ Forge：测试 ， 脚本（部署）
+ Cast：与链交互（查询 ， 发送交易）
+ Anvil：本地测试节点（开发链）

### Forge
+ 使用 Solidity 编写测试，无需 JavaScript。支持 assertEq, vm.expectEmit 等。
+ 自动生成随机输入进行模糊测试，发现边界漏洞。
+ 通过 Solidity 脚本（script/）部署合约到本地或主网。
+ 自动统计每个函数调用的 Gas 消耗，生成优化依据。
+ 使用 solc 编译项目，支持多版本切换。

### **Cast**
+ 查询链数据，如 cast balance <address> 查余额，cast block latest 查区块。
+ cast send 发起交易，调用合约函数。
+ cast call <address> "func()" 调用 view 函数，读取函数返回值。
+ ABI 处理，解析、编码、解码函数调用数据。
+ 连接任意网络，支持 Ethereum、Polygon、BNB Chain 等（通过 RPC）

### **Anvil** 
+ 本地开发链，快速启动一个本地以太坊节点，用于开发和测试。
+ 预充值账户，自动生成 10 个带 ETH 的测试账户（私钥公开）。
+ 时间控制，anvil --fork 可分叉主网状态，cast rpc evm_increaseTime 控制时间。
+ 与 Forge 集成，forge test 默认连接 Anvil，实现快速测试循环。

## Foundry 的核心优势
+ 全 Solidity 开发，无需 JavaScript，测试和脚本都用 Solidity。
+ 极致性能，Rust 编写，编译和测试速度极快。
+ 强大调试，console.log、vm.prank、expectRevert 等。
+ 无缝集成，Forge + Cast + Anvil 三位一体，开箱即用。
+ Gas 分析，内置 Gas 报告，助力优化。

## 总结
Foundry = Anvil（本地链） + Forge（测试/部署） + Cast（链上交互）

构建了一个 全链路、高性能、纯 Solidity 的智能合约开发闭环，是当前最流行的以太坊开发框架之一。
